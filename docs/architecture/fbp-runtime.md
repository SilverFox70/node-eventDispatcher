# Runtime and package boundaries

The Node-only root entry owns components/contracts, graph construction/compilation, streaming execution and event dispatch. /model owns browser-safe JSON graph/catalog/inspection descriptors and validation; /testing owns bounded convenience helpers around the same compiler/runtime. Neither model validation nor serialized catalog metadata can authorize handlers or service effects. Next server/client integration is a later acceptance slice.

A graph is an acyclic GraphSpec plus an application-owned versioned component registry. Compilation checks topology and port compatibility before any process factory runs. A compiled graph is an opaque in-memory handle, not JSON or a durable release ID. Keep all executable objects in the same installed module-format instance; CJS/ESM handles cannot be exchanged. GraphSpec and safe catalog JSON may cross that boundary.

Packets carry separate packetId/jobId and immediate parentPacketIds, with optional correlation key. packet creates a root; derivePacket creates a child; explicit forwarding preserves the original envelope. Public admission is JSON-only. Runtime duplicate protection prevents the same packet entering a node twice in one run. Join groups use jobId/key and cannot reopen after completion. No global result lookup or persistence is present.

Each graph connection is a bounded FIFO stream with backpressure. Different branches may finish in different orders. map/filter are serial per instance, broadcast explicitly derives branch packets, merge forwards ready packets and joinByKey collates bounded keyed products. Close drains; abort discards. Consumers must drain graph outputs concurrently with ingress feeding. See [the examples](../../examples/README.md), especially external feeding/cancellation.

Each run owns fresh processes/channels, cancellation, a first-terminal outcome and bounded safe diagnostics. The flow deadline ends the whole run; taskTimeoutMs bounds an active operation. A configured operation phase cannot exceed the flow budget. Retries default to0; explicit1–5 operation retries require codes, delays and an idempotency commitment. The framework cannot undo external effects or forcibly terminate arbitrary user code; pass signal to real I/O and handle uncertain effects at the application boundary.

runNode exposes every port of one compiled node; runGraph accepts an already compiled graph. Both return terminal, readonly output packets and snapshot. They start collectors before serial ingress feeders and close omitted inputs immediately. Defaults are timeout1000ms and1024 collected outputs across ports; output limit1–100000 and positive safe-integer timeout are configurable. Inputs total at most100000. Overflow rejects TEST_OUTPUT_LIMIT; admission rejects its original error. Component failure returns failed with prior collected packets, cancellation returns cancelled normally. Always assert terminal.status.

Runtime execution records default65536 (configurable1–1048576); keyed join completed-history defaults65536 (configurable1–1048576) and incomplete groups default128 (configurable1–4096). These independent bounds are not silently raised by test helpers. Records do not evict live protection to make room. Typical graphs do not require persistent storage. Rich payloads, controlled cycles and an optional durable host require future explicit contracts.
