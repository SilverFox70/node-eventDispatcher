# Runbooks

Start at [AGENTS.md](../../AGENTS.md) and [the documentation map](../AGENT_FILES.md). Load only the procedure relevant to the task:

- [Plan and review a feature](plan-and-review.md): shared contracts, bounded tasks, concrete proofs and readiness checks.
- [Execute/resume one slice](execute-slice.md): prerequisite/branch check, bounded work and journal handoff.
- [Amend a contract](change-contract.md): concrete proposal, authority, consumer/proof impact and decision status.
- [Verify, hand off and publish](verify-and-publish.md): current-vs-future gates, evidence and authorized external actions.
- [Maintain guidance](maintain-guidance.md): keep entry points, skills, rules, plans and links consistent.

Templates: [execution journal](templates/slice-execution.md) and [architecture decision](templates/architecture-decision.md). Copy when the actual work starts; a template is not an accepted decision, baseline or passing receipt.
